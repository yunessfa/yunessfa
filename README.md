<h2 align="left">About Me</h2>

<p align="left">
  I'm <b>Yuness</b>, a full-stack engineer who takes products from the database schema to the last animation on the page.
</p>

<p align="left">
  Most of my work sits where polished <b>Persian (RTL) interfaces</b> meet serious backends: online stores for brands, a content-managed portfolio for an artist, a trading research platform, a native Android app, and an MCP server that lets AI agents talk to Iranian messengers.
</p>

<p align="left">
  I mainly work with <b>Python, TypeScript, JavaScript and Kotlin</b>, on top of Django REST Framework, React and Node.js, and I deploy what I build myself with Docker, Nginx and PostgreSQL on my own servers.
</p>

<p align="left">
  I care about the details that make software feel finished: clean typography, smooth motion, fast pages, and admin panels that non-technical people can actually use.
</p>
